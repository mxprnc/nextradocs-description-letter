# NextraDocs Description Letter
경력에 존재하는 공백기간, 전 직장 퇴사 이유에 대해 설명해야해서 개설한 문서 보관소입니다.<br/>

전 직장에서 사고를 치거나 괴롭혀서 퇴사한 것은 아니고, 일방적인 퇴사 통보였는데, 현재까지를 돌아보며 왜 그랬는지는 이유는 깨달았는데
그 이유를 적어본다면, 이해해주실것 같아 문서를 작성하게 되었습니다.<br/>

여기까지 방문해주신 분들은 어쩌면 아무 목적 없는 선한 마음으로 확인차 방문해주셨을 거라 생각하긴 합니다.<br/>

동정심을 바래서 적은 것은 아니고 이력서를 보고 놀라셨을 분들께 납득이 될 만한 사실들 정도만 남겨드리고자 글을 적었습니다.
